## Features
- Pure standalone HTML/CSS/JS with zero external runtime dependencies.

- Fluid typography, interactive particle network background, and dark/light mode toggle.
- Concentric timeline node alignment and zero layout shift (CLS).

## Quick Start
Open `index.html` in any modern web browser or serve locally:

```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
