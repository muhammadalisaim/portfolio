SentinelMesh / AegisSOC

An autonomous multi-agent Security Operations Center. Four cooperating agents take an alert from raw SIEM noise to a containment playbook.

  1. AgentTriageFilters anomalous entries from SIEM logs.
  2. AgentThreat IntelEnriches IOCs through VirusTotal and AbuseIPDB.
  3. AgentGraph AnalysisMaps the attack blast radius in Neo4j.
  4. AgentRemediationWrites context-aware containment playbooks.

Pipeline walkthrough ›Triage, Threat Intel, Graph Analysis, Remediation

  • A simulated attack telemetry feed drives the pipeline end to end.
  • A real-time WebSocket incident dashboard shows each incident as it moves through the agents.
